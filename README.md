# Friendsgiving Dashboard

A mobile-friendly dashboard for tracking Friendsgiving RSVPs, arrival/departure timing, overnight stays, bedrooms, dietary restrictions, dishes, kids, baby gear, and notes.

## Current version
This initial version is a static app that stores data in each browser's localStorage. It is ready to deploy as a static site.

## Next step for true shared editing
Connect a hosted datastore/backend so all guests see and edit the same RSVP list. Good options include Supabase, Firebase, or a small Render web service + Postgres.
